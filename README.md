# CV — MY CV DIMZ

Personal Curriculum Vitae website dengan tampilan modern, clean, responsive, dan lightweight.

Website ini dibuat sebagai template CV berbasis HTML, CSS, dan JavaScript tanpa framework atau library eksternal sehingga tetap ringan dan nyaman digunakan pada berbagai perangkat.

## ✨ Features

- Responsive design
- Modern CV layout
- Print / Save as PDF
- Profile section
- Contact information
- Skills & proficiency
- Language section
- Work experience
- Education timeline
- Project showcase
- Additional information
- Lightweight and fast
- No external framework
- No external JavaScript library
